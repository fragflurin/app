# Frag Flurin – Warteliste

Einseitige Warteliste-Seite (HTML/CSS/JS, kein Build). Schriften liegen lokal in `fonts/`.

- Lokal ansehen: `python -m http.server 8000` und dann http://localhost:8000 öffnen.
- E-Mail-Speicherung: in `script.js` die Konstante `ENDPOINT` setzen. Leer = nichts wird gespeichert.
- `datenschutz.html` und `impressum.html` sind Entwürfe mit Platzhaltern, nicht anwaltlich geprüft.
